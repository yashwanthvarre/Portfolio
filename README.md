# Yashwanth Varre Portfolio

A React and Vite portfolio site that highlights experience, GitHub work, technical strengths, and contact details in a polished single-page layout.

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Three.js

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
