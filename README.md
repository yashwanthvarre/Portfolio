# Yashwanth Varre Portfolio

This repository contains a recruiter-facing React portfolio built with Vite. It is designed to communicate senior frontend experience quickly through focused sections on impact, GitHub work, architecture strengths, and direct contact paths.

## Why this project matters

This is not just a personal homepage. It is a packaging layer for your resume:

- translates enterprise frontend experience into a scannable narrative
- highlights the strongest GitHub projects instead of dumping a full repo list
- gives recruiters clear contact actions on desktop and mobile
- demonstrates modern React delivery with a lightweight Vite build

## Tech stack

- React 19
- Vite 8
- Tailwind CSS 4
- Three.js

## Sections

- Hero and summary framing
- experience and impact metrics
- curated GitHub projects
- expertise and education
- direct contact actions

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run build
npm run lint
```

## Improvements made
